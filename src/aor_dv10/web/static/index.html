Memory Channels & Live Memory
Memory Channels
Imports an "AR-DV10 Connect" backup CSV export (companion PC app) and lets you browse/search/tune from it. "Export Live Bank" and "Compare vs Live" below bridge to the receiver's live MA read for one bank at a time - see their own hint for the field caveats that bridge can't fully paper over (mode format, no offset/step-adjust on the live side).
No memory database imported yet.
Bank-Ch Freq (MHz) Mode Name
Live reads have a different confirmed field set than this CSV format (device.py's MemoryChannelInfo docstring): no offset or step-adjust on the live side, and the mode code's exact shape isn't confirmed to match - treat a reported mode difference with that in mind. Frequency/protect/name/pass-flag differences are solid.

      


      
      

        
Live Memory (Receiver)

        
Reads/writes the receiver's own memory banks directly (MA/MX/MR/MW) - the CSV browser to the left works from an offline backup file by default, though its own Export Live Bank / Compare vs Live buttons also reach into live MA reads.

Memory Bank Editor

        
Loads live memory bank(s) from the receiver (MA) into the editable table below. Edit any field, then save just that row, or push a whole loaded bank's rows back (MX) in one go with "Overwrite Bank" / "Overwrite All Loaded Banks" - either overwrite action is DESTRUCTIVE in the same sense any MX write is: it replaces whatever was in that slot, edited or not.

SD Card

        
On the AR-DV10, Rec Stop / Backup / Restore are disabled here (the individual buttons explain why on hover) - a real unit reportedly wedges if these are sent remotely, per the AR-DV1 spec's own "/" stop convention. Stop recording with the front-panel ● key instead.

Search Banks

        
A saved frequency range with its own step/mode (SE/SR) for program search - separate from memory channels.

        

          
          
        

        

          

            
            
            
          

        

        

          
          

            
            
          

          

            
            
          

          

            
            
          

          

            
            
          

        

        

          
          

            
            
          

          

            
          

        

        

      


      
      

        
Scan Groups

        
Search-side (SG) and memory-side (MG) groups link several banks into one scan pass. SG has its own per-group auto-store field; MG does not - that's a real protocol asymmetry, not an omission here.

Danger Zone

        
RS: factory reset. System reset keeps memory data, Full reset erases everything (manual 11.2 items 4/5) - and the 0/1 argument encoding below is an unconfirmed guess, so either button could behave unexpectedly on a real unit. Only use this on hardware you don't mind losing settings/memories on. Click a button once to arm it, again within 3 seconds to actually send it.
